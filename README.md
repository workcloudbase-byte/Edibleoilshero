# Edible Mart — Natural Oils

Deployable static website based on the supplied `edible_mart_3d_website.zip`.

## Repository
- `index.html` — GitHub Pages bootstrap that loads the original supplied website from the ZIP and restores its image assets in-browser.
- `edible_mart_3d_website.zip` — original supplied website package, preserved in the repository.
- `.github/workflows/pages.yml` — automatic GitHub Pages deployment on pushes to `main`.

## Features
- Responsive Edible Mart / Natural Oils storefront
- 3D-style hero presentation
- Product catalogue with search and Tin/Jar filters
- Enquiry cart stored in the browser
- WhatsApp enquiry and contact actions
- Google Maps location embed
- Original ZIP package preserved for reference and deployment

## GitHub Pages
Open **Settings → Pages** and select **GitHub Actions** as the source if it is not already selected. After that, pushes to `main` will publish the site automatically through the included workflow.

No Node.js or build command is required.

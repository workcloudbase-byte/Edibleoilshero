# Edible Mart — Natural Oils

Static website packaged from the supplied `edible_mart_3d_website.zip`.

## Included
- Responsive single-page storefront in `index.html`
- Product catalogue with search and Tin/Jar filters
- Local enquiry cart with WhatsApp handoff
- Supplied product/profile/event imagery in `assets/`
- GitHub Pages deployment workflow in `.github/workflows/pages.yml`

## Deploy with GitHub Pages
1. Open **Settings → Pages**.
2. Set the source to **GitHub Actions** if it is not already enabled.
3. The workflow publishes the repository root whenever changes land on `main`.

No build step or Node.js installation is required; this is a static HTML site.

> Product prices and business-profile details are reproduced from the supplied project and should be reconfirmed before publishing commercial claims.
